# Vietnam Family Rank Quiz

Shared Must / Possible / Pass ranking for **Rony** and **Keren** across the full Vietnam trip.

**Live:** https://vietnam-family-rank-quiz.vercel.app

Stops: Hanoi → Ninh Binh / Tam Coc → Ha Long (Celina) → Hoi An → Da Nang → Phu Quoc.

## Local
```bash
npm install
npm start
```
Open http://127.0.0.1:8787

## Notes
Votes sync via GitHub `data/votes.json` when `GITHUB_TOKEN` is set (production).
